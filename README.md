# 408 计算机学科专业基础 · 复习知识库

数据结构 · 计算机组成原理 · 操作系统 · 计算机网络。
按知识树组织的考点、算法、代码，以及**你自己的思路记录**。

和隔壁 [`../Mathematics`](../Mathematics) 是姊妹项目，共用同一套引擎，内容各自独立。
主色是青绿，数学站是蓝 —— 两个标签页并排开时一眼能区分。

## 怎么用

**看**：双击 `index.html` 就能打开，不需要任何环境或联网。

**更新**：不在网页上编辑，而是**直接跟 Claude 说**。比如：

> 我在复习页面置换算法，这是我跟 AI 的对话，帮我整理进去：〈粘贴对话〉

Claude 会自己判断该放到哪门课、哪一章、哪个专题，然后更新对应文件。你刷新页面就能看到。

也可以直接指定位置：

> 整理到 `os/memory/replace`

## 页面上的约定

内容块用颜色区分来源，扫一眼就知道在看什么：

| 颜色 | 含义 |
|---|---|
| 🔵 蓝 | 定义、原理、必背结论 |
| 🟣 紫 | 方法论、算法流程 |
| 🟢 绿 | **你自己的思路和顿悟** |
| 🔴 红 | 易错点、会丢分的地方 |
| 🟡 琥珀 | 例题卡 |
| ⬛ 深色卡片 | 代码 / ASCII 示意图 |

例题的**思路 / 解答 / 点评默认折叠**，方便先自己想再对答案。

## 快捷键

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `e` | 展开 / 折叠本页所有解答 |
| `[` `]` | 上一篇 / 下一篇 |
| 顶栏 `◐` | 明暗主题（跟随系统 → 浅色 → 深色） |

## 结构

```
content/manifest.js    知识树：4 门课 + 跨科主线 + 随笔
content/ds/            数据结构（45 分）
content/co/            计算机组成原理（45 分）
content/os/            操作系统（35 分）
content/net/           计算机网络（25 分）
content/threads/       跨科手法主线（局部性 / 分层 / 空间换时间 …）
assets/  vendor/       样式、脚本与本地公式渲染
```

侧栏里灰色斜体的专题 = 还没有内容，跟 Claude 说一声就会填上。

已有一页示范内容：**数据结构 › 4 串 › KMP 与 next 数组**，
新页面的写法照它抄即可。

## 本地起服务（可选）

直接双击 `index.html` 就够用。想用 http 方式访问的话：

```bash
python -m http.server 5181
```

（用 5181 是为了和数学站的 5180 错开，两个可以同时开着。）

技术细节和内容格式规范见 [CLAUDE.md](CLAUDE.md)。
